# Деплой: GitHub и проверка с телефона

## Вариант A. Проверить прямо сейчас (превью платформы)

После сборки в этом чате появляется кнопка/ссылка предпросмотра — откройте её
в браузере телефона. Это тот же dev-сервер, голос Emma уже подключён.

## Вариант B. Залить код на GitHub

Репозиторий готов к пушу (история коммитов уже есть). Понадобится ваш
GitHub-аккаунт:

1. Создайте **пустой** репозиторий на https://github.com/new
   (например, `cassiopea-kiosk`, без README и .gitignore).
2. Локально:

```bash
cd /home/z/my-project
git remote add origin https://github.com/<ВАШ_ЛОГИН>/cassiopea-kiosk.git
git push -u origin main
```

При запросе логина/пароля вставьте Personal Access Token
(Settings → Developer settings → Fine-grained tokens → Contents: Read and write).

Либо просто пришлите токен ассистенту — он запушит сам.

## Вариант C. Живая ссылка с телефона (Vercel, ~5 минут, бесплатно)

GitHub Pages не подходит: приложению нужны серверные API-роуты.
Vercel подхватит репозиторий автоматически:

1. Откройте https://vercel.com/new → **Import Git Repository** → ваш `cassiopea-kiosk`.
2. Framework: Next.js (определяется сам), ничего не меняйте → **Deploy**.
3. Через пару минут получите адрес вида `https://cassiopea-kiosk.vercel.app` —
   откройте с телефона: HTTPS включён сразу, значит микрофон ассистента работает.

### Что работает на Vercel «из коробки»

- Каталог, коллекции, примерка, избранное — полностью.
- Озвучка Emma (Edge TTS) — полностью (WebSocket-клиент не требует ни Python, ни ключей).
- Ассистент — отвечает локальным движком по каталогу (fallback).

### Что подключить по желанию

LLM-ответы ассистента и серверное распознавание речи используют z-ai SDK,
который в этой среде читает конфиг `~/.z-ai-config`. Для полного LLM на
внешнем хостинге положите копию этого файла рядом с приложением и укажите
путь в переменной окружения — без него приложение продолжит работать на
локальном движке (все ответы по каталогу и дому останутся доступными).

## Требования

- Node ≥ 22 (в среде сборки) — нужен встроенный WebSocket.
- HTTPS обязателен для микрофона (Vercel даёт его автоматически).
- Переменные окружения не обязательны: `TTS_VOICE` (голос, по умолчанию
  `en-US-EmmaMultilingualNeural`), `TTS_RATE` (темп, по умолчанию `+0%`).
