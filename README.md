# Cassiopea — интерактивный каталог ювелирного дома

Kiosk-приложение для планшетов в торговых залах бутиков Cassiopea (cassiopea.ru).
Каталог из 136 изделий и 9 коллекций, голосовая ассистентка «Кассиопея»,
виртуальная примерка, избранное — в фирменной стилистике дома (созвездие,
звёзды, золото на глубоком синем).

## Возможности

- **Каталог** — кольца, серьги, подвески, браслеты с описаниями и характеристиками
  (данные собраны с cassiopea.ru, фото — только родные галереи изделий).
- **Коллекции** — карточки коллекций с манифестами и составом.
- **Голосовой ассистент** — понимает речь и текст, отвечает по базе знаний дома,
  умеет открывать нужные экраны. Озвучка — нейроголос Microsoft
  **en-US-EmmaMultilingualNeural** (мягкий женский тембр, поддерживает русский).
- **Виртуальная примерка** — фронтальная камера планшета.
- **Избранное** — подборка изделий для консультанта.

## Озвучка (Edge TTS)

Синтез речи работает на чистом WebSocket-клиенте (`src/lib/edge-tts.ts`) —
без Python и npm-зависимостей, поэтому один и тот же код работает на сервере
kiosk-а, в браузере (резерв, если API недоступен) и на любом Node-хостинге.

Сменить голос (полный список: `edge-tts --list-voices`):

```bash
# через переменную окружения (принимаются и короткие имена edge_EmmaMultilingual)
TTS_VOICE=ru-RU-SvetlanaNeural npm run dev
```

или константой `KIOSK_VOICE` в `src/lib/edge-tts.ts`.

## Запуск

```bash
bun install        # или npm install
bun run dev        # http://localhost:3000
```

Продакшен-сборка: `bun run build && bun run start` (standalone, Node ≥ 22).

## Структура

```
src/app/                 страницы и API-роуты (tts, assistant, asr)
src/components/kiosk/    экраны kiosk-а, ассистент, примерка
src/lib/edge-tts.ts      Edge TTS клиент (WebSocket, изоморфный)
src/lib/assistant-engine.ts  локальный движок ответов (фолбэк LLM)
src/lib/catalog.ts       доступ к каталогу
src/data/catalog.json    136 изделий (slug, цены, фото, характеристики)
public/images/products/  фотогалереи изделий
```
